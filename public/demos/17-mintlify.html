客户 MCP 接入

服务方发放 MCP URL 和 MCP key，客户通过授权资源 id 作为 chipId 发起 smoke test。

  1. 准备MCP URL + MCP key
  2. 配置生成客户本地私有配置
  3. 确认调用 agentx_whoami 查看资源
  4. 烟测用 chipId 启动只读会话

opencode

"type": "remote",
"url": "https://agentx.example/mcp",
"headers": { "Authorization": "Bearer ***" }

codex

codex mcp add agentx-remote \
  --url <AGENTX_MCP_URL> \
  --bearer-token-env-var AGENTX_MCP_KEY
