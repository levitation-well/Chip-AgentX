spawn 示例
  1. 客户端连接 Remote MCP 后先调用 agentx_whoami({})。
  2. 确认 key id/fingerprint、allowedModels、resources 和 cwdExposed=false。
  3. 从 permissions.resources[].id 选择资源作为 chipId。
  4. 不要传 cwd、env、自定义 systemPrompt 或完整 key。
